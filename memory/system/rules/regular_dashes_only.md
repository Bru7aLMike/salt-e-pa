# Regular dashes only

Use a plain hyphen-minus ("-") wherever a dash is needed. Do not use em dashes,
en dashes, or a double-hyphen standing in for one.

- Why: em dashes and double dashes are a common tell of machine-generated text,
  and they render inconsistently across terminals, editors, and plain-text
  files. A single dash style keeps output uniform and readable everywhere.
- How to apply: when a sentence wants a dash, write "-" (optionally spaced) and
  rephrase if the sentence leans on dashes so heavily that hyphens read badly.
